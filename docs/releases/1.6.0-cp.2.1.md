# CrossPink 1.6.0-cp.2.1

Ngày phát hành: 01/09/2026

## Thay đổi chính

- Rút gọn tên hiển thị tiếng Anh từ **Vietnamese Lunar Calendar** thành **Lunar Calendar** trên toàn bộ giao diện liên quan. Tên tiếng Việt vẫn là **Lịch Âm Việt Nam**.
- Giữ nguyên tên nội bộ và đường dẫn cache để bản cập nhật không làm mất dữ liệu đã tải.

## Cập nhật OTA

Các bản CrossPink trước đó đã hiểu định dạng `-cp.N.M`, vì vậy có thể nhận `1.6.0-cp.2.1` trực tiếp qua OTA. Firmware VNS hoặc CrossPoint vẫn cần flash CrossPink thủ công 1 lần vì updater chỉ chấp nhận release cùng edition.

## File cài đặt

- `firmware.bin`: Xteink X3 và X4 dùng ESP32-C3.
- `firmware-x4pro.bin`: Xteink X4 Pro dùng ESP32-S3.
- Mỗi image đi kèm file `.sha256`; hãy dùng đúng image của thiết bị.

## Giới hạn xác nhận

Release được kiểm tra bằng host test, phân tích tĩnh và build đa môi trường. Chưa có xác nhận trực tiếp trên thiết bị vật lý về hiển thị chuỗi mới hoặc OTA/rollback.
