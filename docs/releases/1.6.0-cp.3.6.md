# CrossPink 1.6.0-cp.3.6

Ngày phát hành: 03/09/2026

## Thay đổi chính

- Sửa trang Settings trên hotspot có thể treo hoặc không mở được. Web server không còn quét catalog font trên thẻ SD ngay trong request HTTP ở minimal network boot; thao tác đọc/lưu cài đặt không liên quan cũng không kích hoạt quét thẻ đồng bộ.
- Giữ nguyên font SD và cỡ chữ đang chọn khi catalog font chưa được nạp, tránh việc mở hoặc lưu Settings qua web vô tình hiển thị sai hay thay lựa chọn hiện tại.
- Tăng khả năng OPDS hoạt động trên X3/X4 có RAM hạn chế. Trước khi khởi tạo Wi-Fi, TLS và parser feed, firmware giải phóng font SD cùng catalog có thể dựng lại nhưng vẫn giữ cấu hình để phục hồi sau khi thoát chế độ mạng.
- Hoãn cấp phát Expat và vùng chứa entry OPDS tới khi byte đầu tiên của response body tới, giảm cạnh tranh peak heap với quá trình bắt tay TLS. Response rỗng vẫn được phát hiện là feed không hợp lệ.
- Phân biệt lỗi HTTP của OPDS với lỗi kết nối: server trả mã lỗi sẽ hiển thị `Failed to fetch feed (HTTP N)`, còn lỗi DNS/TCP/TLS hoặc response không hoàn tất sẽ hiển thị lỗi kết nối.

## Cập nhật OTA

CrossPink `1.6.0-cp.3.5` có thể nhận `1.6.0-cp.3.6` trực tiếp qua OTA. Firmware VNS hoặc CrossPoint vẫn cần flash CrossPink thủ công 1 lần vì updater chỉ chấp nhận release cùng edition.

## File cài đặt

- `firmware.bin`: Xteink X3 và X4 dùng ESP32-C3.
- `firmware-x4pro.bin`: Xteink X4 Pro dùng ESP32-S3.
- Mỗi image đi kèm file `.sha256`; hãy dùng đúng image của thiết bị.

## Kiểm chứng

- Toàn bộ 398 host test đạt, gồm 3 regression test mới cho parser OPDS: khởi tạo lười, parse feed chia nhiều chunk và từ chối response body rỗng.
- Build cục bộ `default`, `sticky`, `gh_release` và `x4pro-gh_release` đạt trên ESP32-C3 và ESP32-S3. Hai binary phát hành nhúng đúng phiên bản `1.6.0-cp.3.6`; workflow phát hành tiếp tục đối chiếu version, ESP checksum/validation hash và SHA-256 trước khi đăng asset.
- `git diff --check` và kiểm tra `clang-format` cho toàn bộ file C/C++ thay đổi đều đạt.

## Giới hạn xác nhận

Release chưa được kiểm tra trực tiếp trên thiết bị vật lý. Việc mở Settings tại `crosspink.local`, tải feed từ OPDS server thực và mức heap còn lại trong bắt tay TLS vẫn cần smoke test trên X3/X4 thật. Vì chưa có số đo heap/timing trên thiết bị nên không tuyên bố mức cải thiện định lượng.
